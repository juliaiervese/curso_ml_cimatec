# Solução do projeto de Reconhecimento Facial

Esta documentação marca a etapa de implementação do sistema de reconhecimento
facial utilizando a estrutura do projeto CCDS.

Objetivos desta etapa:
- preparar a base de pessoas autorizadas;
- gerar embeddings por rosto;
- comparar com a amostra de teste;
- decidir com base no limiar configurado;
- registrar resultados em `reports/resultados.csv`.

Esta etapa representa a solução funcional do projeto, antes da entrega final
na Aula 20.
